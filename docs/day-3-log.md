
# Day 3 - Staff Login Validation

## Objective
Complete client-side validation for the hospital staff login form.

## Work Completed
- Email required-field validation
- Basic email format validation
- Password required-field validation
- Minimum password length validation
- Error messages and invalid-field styling
- Validation success message

## Files
- index.html
- css/style.css
- js/app.js

## Testing
Record the actual results of the four validation tests.

## Learning
- DOM manipulation
- Form submit events
- preventDefault()
- Regular expressions
- classList.add() and classList.remove()
- Client-side validation

## Limitation
