# Sri Veda Multispeciality Hospital
## Appointment & Patient Management Portal

### Client
Sri Veda Multispeciality Hospital, Hyderabad

### Project Objective

Develop a web-based portal to simplify hospital appointment
management and improve the process of managing patients,
doctors and appointments.

### Users

1. Patients
2. Hospital Staff
3. Administrator

### Patient Features

- View doctors
- View doctor details
- Book appointments
- View appointments
- Cancel appointments

### Hospital Staff Features

- Staff login
- View appointments
- View patient information
- Update appointment status

### Administrator Features

- Manage doctors
- Manage staff
- Manage appointments
- View dashboard statistics

### Frontend Responsibilities

- Responsive UI
- Forms
- Form validation
- Navigation
- Dashboard
- API integration
- Error handling
- Testing
